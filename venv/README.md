# 🤖 AI Virtual Assistant

## Overview

This project is a local AI Virtual Assistant built using Streamlit and Ollama (Llama 3.2).

The assistant can:

- Answer user questions
- Open websites such as Google, YouTube, and GitHub
- Display the current time and date
- Maintain chat history
- Provide a simple and interactive chat interface

This project was developed as part of the Hex Softwares Artificial Intelligence Internship Program.

---

## Features

- 🤖 AI Chat Assistant
- 🌐 Open Google
- ▶️ Open YouTube
- 💻 Open GitHub
- 🕒 Current Time
- 📅 Current Date
- 🗑️ Clear Chat
- 💬 Chat History
- 🧠 Local AI using Ollama
- 🎨 Interactive Streamlit Interface
